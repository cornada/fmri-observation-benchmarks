# Citing the artifact

For this code version, cite **fMRI Observation Benchmarks, version 1.0.0 (2026)** and the [release URL](https://github.com/cornada/fmri-observation-benchmarks/releases/tag/v1.0.0). The five paper folders give the associated manuscript titles. Publication identifiers will be added after publication.

If using the MSC array, also cite the [Midnight Scan Club dataset](https://doi.org/10.18112/openneuro.ds000224.v1.0.4) and its associated publication listed in that dataset record. The operator node meanings and exported session/edge order are described in paper 01.
